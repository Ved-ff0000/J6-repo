# Implementation and deployment status

The user authorized continuation through all remaining phases without approval pauses.
The repository now contains a **24-stage MVP implementation**, not a certified,
production-ready legal-compliance service. Stage numbers describe implemented areas,
not successful deployment, legal accuracy, complete enterprise feature coverage or
production-security certification. Do not use real leases yet.

## Remaining-stage coverage

## Run and verify

```sh
python scripts/init_dev_env.py  # preserves existing private .env
# Provision PostgreSQL, Redis, MinIO and enabled vector/graph dependencies:
docker compose up --build
# Standalone dev, with virtualenv and dependencies already available:
(cd backend && python -m alembic upgrade head)
(cd backend && python -m app.operations.worker --once)
./scripts/check.sh
(cd backend && python -m app.evaluation --gold ../evaluation/golden.json)
(cd frontend && npm audit --audit-level=high)
```

Only synthetic inputs are permitted until deployment/identity/scanning/legal-quality
gates are completed. Enabling review or notifications does not enable paid LLM calls;
all prior extraction flags, indexed-source checks, quota and explicit egress consent
remain in force. `.env.example` describes new flags. See
[governed operations runbook](governed-operations.md) and
[production launch gates](production-readiness.md).
